# 0.1.0-alpha.1

Erste implementierte Lieferung vom 21.10.2026. Minecraft 1.21.1, NeoForge 21.1.264, Java 21.

## Spielinhalt

- Survival → Primitive Core → Wasserrad → mechanische Presse → Pressed Core → Mechanical Core.
- Fünf neue Items mit stabilen `omega:*`-IDs. KubeJS registriert sie; vorhandene Vanilla-Texturen mit Tint dienen als Alpha-Grafik.
- Acht Rezepte, darunter Ersatzrezepte für Create-Wasserrad und -Presse. Handgefertigte Kupferplatten ermöglichen den Bootstrap vor der ersten Presse.
- Zwölf FTB-Quests auf Deutsch und Englisch mit festen IDs, optionalem Nahrungspfad und kleinen Lebensmittel-/Eisenbelohnungen.
- Verbrauchender Lieferauftrag über 120 Kupferplatten. Er misst keine Produktionsrate. Der Pressed Core verwendet einen nativen Create-Pressrezepttyp.

## Technik und Abnahme

13 eigenständige Moddateien auf dem Client, zwölf auf dem Server. Create, KubeJS und JEI bringen weitere Bibliotheken eingebettet mit. Exakte Versionen, Quellen, Lizenzlabels und Hashes: [pack/lock.json](../../pack/lock.json). Die 473er-Wunschliste bleibt Ausbauplanung.

Der Exporter erzeugt einen CurseForge-Client-ZIP und ein Server-Kit ohne verteilte Fremd-JARs. GitHub Actions prüft Planung, Lock und Questgenerator, führt fünf Regressionstests aus und baut die ZIPs. Die CI behauptet keinen Minecraft-Laufzeittest.

Der [Testbericht](../../tests/evidence/v0.1.0-alpha.1/REPORT.md) enthält echte Serverprüfungen für Registry, Crafting, Rezepttyp, Questimport, Lieferung und Neustartpersistenz. Client-/GUI-Test, physisch betriebene Presse und Zwei-Spieler-Durchlauf stehen aus. Balancing und Speicherbedarf sind nicht gemessen.

Spätere Zeitalter, elektrische Maschinen, eigene Bosse, Omega-Reaktor, Sterne und die eigene Java-Mod bleiben geplant. Nächster Schritt ist die gemeinsame Alpha-Abnahme, danach ein kleiner Abschnitt des elektrischen Zeitalters.
