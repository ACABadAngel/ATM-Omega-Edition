# 0.1.0-alpha.2

Fortsetzung der ersten Alpha vom 21.10.2026. Minecraft 1.21.1, NeoForge 21.1.264, Java 21. Der Modlock mit 13 Client-/12 Serverdateien, fünf Item-IDs, acht Rezepten und zwölf bilingualen Quests bleibt erhalten.

- Offline-Backup, vollständige SHA-256-Verifikation und Restore in einen separat installierten Server mit demselben Lock. Bestehende Welten werden nicht überschrieben; laufende Welten werden über Minecrafts Betriebssystem-Sperre erkannt.
- Echter Linux-Test: 65 Dateien gesichert und identisch wiederhergestellt. Nach Serverstart bleiben drei Mechanical Cores und 120 Platten Lieferfortschritt erhalten.
- Eine echte Create-Presse verarbeitet auf dem Dedicated Server Primitive Core und Kupferbarren. Antrieb: fließendes Wasser, kleines Wasserrad, Welle; 8 RPM. Testfixture wird nicht mit dem Pack exportiert.
- Installer lehnt auch benutzerdefiniert benannte vorhandene Welten ab. Ein abgebrochener NeoForge-Installationslauf wird trotz bereits angelegter Startskripte erneut ausgeführt; erst ein erfolgreicher Installerlauf setzt die Fertig-Markierung.
- Zwölf Regressionstests und aktualisierte Claude-Übergabe. [Fabrik-Anleitung](../first-factory.md) und [Backup-Anleitung](../backups.md).

## Update und offene Abnahme

Die Spielinhalte der ersten Alpha ändern sich nicht. Ein neues Clientprofil kann aus dem Alpha-2-ZIP importiert werden. Vor Übernahme einer vorhandenen Welt immer offline sichern; der Installer ist kein In-place-Updater. Für Rücksicherung das gleiche Modlock verwenden.

Clientstart, Questoberfläche, realer Survival-Durchlauf, zwei echte Spieler und native Windows-Backup-/Installationsprüfung stehen weiterhin aus. Das elektrische Zeitalter bleibt der nächste Inhaltsabschnitt nach der Alpha-Abnahme.
